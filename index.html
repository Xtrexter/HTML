Linux Komut Satırına Giriş: Yeni Başlayanlar İçin Kapsamlı Rehber

👤 Murat Kaya 📅 10 Mart 2025 ⏱️ 30 dk okuma 👁️ 8.9K görüntülenme

Linux'a yeni başlıyorsanız, komut satırı (terminal) başta korkutucu gelebilir. Ancak birkaç temel komutu öğrendikten sonra, grafik arayüzden çok daha hızlı ve güçlü bir şekilde sisteminizi yönetebileceğinizi göreceksiniz. Bu rehberde, en çok kullanılan Linux komutlarını gerçek örneklerle öğreneceksiniz.

1. Terminal Nedir ve Nasıl Açılır?

Terminal (veya konsol), Linux sisteminde komut girmenizi sağlayan metin tabanlı arayüzdür. Grafik masaüstü ortamlarında genellikle Ctrl+Alt+T tuş kombinasyonuyla açılır. Sunucularda ise doğrudan SSH ile terminale bağlanırsınız.

💡 İpucu

Terminal açıkken Tab tuşuna basarak komut ve dosya adı tamamlama yapabilirsiniz. Bu, yazım hatalarını önler ve çok zaman kazandırır.

2. Temel Dosya ve Dizin Komutları

Linux'ta her şey bir dosyadır. Dosya sistemiyle etkileşim kurmak için aşağıdaki komutları kullanırsınız:

bash
# Mevcut dizini göster $ pwd /home/kullanici # Dizin içeriğini listele $ ls -la total 56 drwxr-xr-x 8 user user 4096 Mar 15 10:30 . drwxr-xr-x 45 user user 4096 Mar 14 09:15 .. -rw-r--r-- 1 user user 220 Mar 01 14:22 .bash_profile # Dizin oluştur $ mkdir -p projeler/web/frontend # Dizin değiştir $ cd projeler/web/ # Dosya kopyala $ cp kaynak.txt hedef.txt $ cp -r klasor/ yedek_klasor/ # klasör kopyala # Dosya taşı / yeniden adlandır $ mv eski_ad.txt yeni_ad.txt # Dosya sil (DİKKATLİ KULLANIN!) $ rm dosya.txt $ rm -rf bos_klasor/ # klasör sil
⚠️ Dikkat

rm -rf komutu geri alınamaz! Özellikle root olarak çalışırken son derece dikkatli olun. Silmeden önce ls ile dosyaları kontrol edin.

3. Dosya İçeriği Görüntüleme

Dosya içeriklerini terminal üzerinden okumak için birkaç farklı yöntem vardır:

bash
# Dosyanın tamamını göster $ cat /etc/hosts # Sayfa sayfa göster (q ile çık) $ less /var/log/syslog # Son 20 satırı göster ve canlı takip et $ tail -f -n 20 /var/log/nginx/access.log # İlk 10 satır $ head -n 10 access.log # İçinde kelime ara $ grep -n "ERROR" /var/log/app.log $ grep -ri "hata" /var/log/ # büyük/küçük harf duyarsız, recursive

4. Süreç (Process) Yönetimi

Çalışan süreçleri izlemek ve yönetmek Linux sistem yönetiminin temel becerilerinden biridir:

bash
# Tüm süreçleri listele $ ps aux USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND root 1 0.0 0.1 225788 9120 ? Ss Mar14 0:10 /sbin/init # Gerçek zamanlı süreç izle $ htop # kurulu değilse: apt install htop # Belirli süreci bul $ pgrep -fl nginx 1234 nginx: master process 1235 nginx: worker process # Süreci sonlandır $ kill -9 1234 # PID ile $ pkill nginx # isim ile

5. Paket Yönetimi (APT)

Ubuntu ve Debian tabanlı dağıtımlarda yazılım kurulumu APT paket yöneticisi ile yapılır:

bash
# Paket listesini güncelle $ sudo apt update # Kurulu paketleri yükselt $ sudo apt upgrade -y # Yazılım kur $ sudo apt install vim curl wget git -y # Yazılım kaldır $ sudo apt remove --purge paket_adi # Paket ara $ apt search text-editor # Artık gerekli olmayan paketleri temizle $ sudo apt autoremove -y && sudo apt autoclean
✅ İyi Uygulama

Sunucularınızı düzenli olarak güncelleyin. Güvenlik yamaları için unattended-upgrades paketini kurarak otomatik güvenlik güncellemelerini etkinleştirebilirsiniz.

Diğer Dağıtımlarda Paket Yönetimi

bash
# RHEL / CentOS / Fedora (DNF) $ sudo dnf install nginx $ sudo dnf update -y # Arch Linux (Pacman) $ sudo pacman -Syu # güncelle $ sudo pacman -S nginx # kur # openSUSE (Zypper) $ sudo zypper install nginx

6. Ağ Komutları

Ağ bağlantısını kontrol etmek ve sorun gidermek için yaygın kullanılan komutlar:

bash
# IP adreslerini göster $ ip addr show $ hostname -I # kısa yol # Bağlantı testi $ ping -c 4 google.com PING google.com: 56 data bytes 64 bytes from 142.250.185.46: icmp_seq=1 ttl=116 time=12.4 ms # Açık portları listele $ ss -tlnp $ netstat -tlnp # eski yöntem # DNS sorgula $ dig google.com $ nslookup google.com # HTTP isteği gönder $ curl -I https://example.com # header bilgisi $ wget -q -O - https://api.github.com | head

7. İzinler ve Sahiplik

Linux'ta her dosyanın bir sahibi ve izin seti vardır. Doğru izinleri ayarlamak güvenlik açısından kritik öneme sahiptir:

bash
# İzin değiştir $ chmod 755 script.sh # rwxr-xr-x $ chmod +x script.sh # çalıştırılabilir yap $ chmod -R 644 /var/www/html/ # recursive # Sahip değiştir $ sudo chown www-data:www-data /var/www/html/ $ sudo chown -R user:group /home/user/ # İzinleri oku # -rw-r--r-- = 644 = owner:rw group:r others:r # drwxr-xr-x = 755 = owner:rwx group:rx others:rx

Bilmene Sevindirecek İpuçları

Her gün zaman kazandıracak, verimliliğini artıracak pratik Linux hileleri.

⚡
Ctrl+R ile Komut Geçmişinde Arama
Terminalde Ctrl+R tuşuna basarak yazdıklarınızı komut geçmişinde geriye doğru arayabilirsiniz. Uzun komutları tekrar yazmaktan kurtulun.
Ctrl+R → "nginx" yazın → Enter
🔁
!! ile Son Komutu Tekrarla
Önceki komutu sudo ile çalıştırmak mı gerekti? "sudo !!" yazmanız yeterli. "!" işareti son komutu temsil eder.
sudo !!
🖥️
Tmux ile Oturum Yönetimi
SSH bağlantınız koptuğunda çalışan komutlarınız durmasın. Tmux ile oturumları saklar, sonra istediğiniz zaman geri dönersiniz.
tmux new -s mysession
🔍
xargs ile Toplu İşlem
find ile bulduğunuz dosyaları xargs ile toplu silme, taşıma veya işleme uygulayın. Her dosya için ayrı komut yazmaktan kurtulun.
find . -name "*.tmp" | xargs rm -f
📋
alias ile Kısayol Oluştur
Sık kullandığınız uzun komutları kısa takma adlarla kaydedip anında kullanın. ~/.bashrc dosyasına ekleyerek kalıcı hale getirin.
alias ll='ls -la --color=auto'
📦
rsync ile Akıllı Yedekleme
cp yerine rsync kullanın; sadece değişen dosyaları kopyalar, bant genişliğini verimli kullanır ve SSH üzerinden uzak yedekleme yapar.
rsync -avzP src/ user@server:/backup/
🧹
Journalctl ile Log Yönetimi
Sistem loglarını zamanla, servise göre ve önceliğe göre filtreleyin. Eski logları silerek disk alanı kazanın.
journalctl --vacuum-time=30d
🔐
SSH Config ile Hızlı Bağlanma
~/.ssh/config dosyasına sunucu bilgilerini ekleyerek uzun ssh komutları yerine kısa takma adlarla bağlanın.
ssh webserver # ssh admin@192.168.1.10 -p 2222 yerine
📊
watch ile Komut Çıktısını İzle
Bir komutun çıktısını belirli aralıklarla tekrarlayın. Disk doluluk oranını, ağ bağlantılarını veya log çıktısını canlı izlemek için mükemmel.
watch -n 2 "df -h && free -m"
